# Integration Hub

Local shared-host Rails Engine with MVC + CQRS. Web: `/integration`; Bearer API: `/api/v1/integration`. Public machine ingress: `POST /webhooks/integration/:public_id`, authenticated only by per-connection HMAC.

Seven repository contracts are registered by IntegrationServiceProvider. Connection credentials, payload and review notes use Active Record Encryption. Eight database permissions separate metadata, creation, administration, review and sensitive-payload access. No default HR/employee access. Connections start inactive; generated signing secret is returned only in create/rotation responses. Row locks serialize reception with key/status changes. MySQL composite FK/unique/status constraints and optimistic versions protect ownership and race conditions. Audit/outbox are atomic and carry IDs/changed fields only.

Ingress middleware caps raw reads at 64 KiB + 1 before Rails parameter logging and suppresses implicit JSON parsing. HMAC signs timestamp.event_id.raw_body, accepts 300-second skew, validates schema/UTF-8/depth after authentication. Duplicate identical bytes are idempotent; conflicting reuse is 409. Case-sensitive Event IDs. Review only acknowledges/rejects a receipt; it does not apply business changes.

Outbound workspace: `/integration/outbound`, with five explicit web routes and five Bearer API routes. Durable MySQL queue, minute dispatch, Sidekiq delivery, immutable encrypted payload/event identity, attempt journal, bounded retry/backoff, dead-letter filter and optimistic replay are implemented. Operator-only `INTEGRATION_TARGETS_JSON` defaults to an empty allowlist. Transport uses public IPv4 DNS validation/pinning, HTTPS:443/TLS verification, proxy disabled, bounded time/body and no redirects. Requester grants and connection/company status are rechecked before sending. Receiver deduplication is required for the network/commit crash window; delivery is not exactly once.

Partial DJI port: provider-specific adapters, ERP/government exports/external references, business-domain dispatch and retention scheduling are not implemented. App limits complement proxy body/timeouts/TLS/WAF. This uses shared host models/observer and is not a standalone independently deployable gem.

See root `HUONG_DAN_OUTBOUND_QUEUE_LARAVEL_RUBY.txt` and `HUONG_DAN_INTEGRATION_WEBHOOK_LARAVEL_RUBY.txt` for three side-by-side tables and signature examples. The existing event_sink protocol is distinct from the new inbound protocol.

Restricted Integration event prefixes also require integration.read before every realtime transmit, including existing subscriptions. The provider registers permission names; the platform gate retains no reloadable class references. Valid UTF-8 payload bytes are preserved from binary HTTP input through encryption; HMAC/digest always use the original bytes.

Audit portal: `/integration/audit` and `/api/v1/integration/audit`. Requires `integration.read` + `integration.audit.read`, independent of broad global `audit.read`. The namespaced Integration::AuditLogPolicy scopes existing audit rows to company/four Integration record types. Explicit safe metadata projection, 30-day default/93-day maximum date window, strict filters, ID cursor pagination, source-linked action KPIs and bounded batch source lookup. Attempts include safe HTTP/outcome metadata; deleted sources keep history without a source link. No arbitrary metadata/raw body/credentials/actor contact details, no inferred historical before/after state. Read `HUONG_DAN_AUDIT_INTEGRATION_LARAVEL_RUBY.txt`.

Outbound integrity gate: the generic enqueue/replay/worker paths share OutboundEnvelope schema/size/UTF-8 validation and reserve payroll/erp/government event roots for future source-bound bridges. Worker/replay also compare the persisted SHA256 with actual decrypted bytes. Invalid content/ciphertext is blocked before HTTP without an attempt, with atomic audit/outbox. The narrowly guarded quarantine status write skips Rails' automatic decrypting length validator, retaining locks, DB constraints and callbacks; ordinary writes keep validation. Metadata serialization avoids decrypting payload. Checksum is not protection against an operator able to rewrite both bytes and digest. This generic gate is now complemented by the separately authorized payroll descriptor bridge below. See root HUONG_DAN_BAO_VE_OUTBOUND_LARAVEL_RUBY.txt.

Payroll descriptor bridge: GET/POST `/integration/payroll-exports/:id` and Bearer API equivalents. Requires Integration read/send plus Payroll read/export-read/notify. An immutable source FK, deterministic source/connection/target key, artifact verification and server-generated `payroll.export.ready` descriptor bind each delivery; no salary CSV/employee rows/download URL are transmitted. Worker and replay recheck source grants and exact descriptor/integrity. Acquire delivery/connection/source locks before consistent grant reads, bypass query cache under locks. Delivery metadata, audit and realtime derive current source visibility; realtime resolves the trusted company OutboxEvent ID. Generic roots/bridge key namespace remain reserved. New Payroll source contract and Integration bridge contract bring total bindings to 36. Read `HUONG_DAN_BRIDGE_BANG_LUONG_LARAVEL_RUBY.txt`. External targets remain disabled locally; accounting/provider uploads and full DJI parity remain incomplete.
